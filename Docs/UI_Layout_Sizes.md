## Размеры по компонентам

### 1. Консоль (Windows Terminal / PowerShell)
- **Ширина**: 160 символов
- **Высота**: 45 строк
- **Буфер**: 160 x 2000 строк

### 2. Terminal.Gui Main Window
- **Ширина**: `Dim.Fill()` = вся ширина консоли (160)
- **Высота**: `Dim.Fill()` = вся высота консоли (45)

### 3. Status Bar
- **Ширина**: `Dim.Fill()` = 160 символов
- **Высота**: 1 строка
- **Позиция**: Y = 0 (верх окна)

### 4. Logs Panel (слева)
- **Ширина**: `Dim.Percent(70)` = 70% от 160 = **112 символов**
- **Высота**: `Dim.Fill() - 3` = 45 - 1 (status) - 2 (input) = **42 строки**
- **Позиция**: X = 0, Y = 1

### 5. Commands Panel (справа)
- **Ширина**: `Dim.Fill()` (от Pos.Percent(70)) = 30% от 160 = **48 символов**
- **Высота**: `Dim.Fill() - 3` = **42 строки**
- **Позиция**: X = Pos.Percent(70), Y = 1

### 6. Input Frame
- **Ширина**: `Dim.Fill()` = **160 символов**
- **Высота**: 2 строки (поле ввода + hint)
- **Позиция**: Y = Dim.Fill() - 2 (низ окна)

## Размеры логов

### Startup Box (логи запуска)
```
┌ЗАГОЛОВОК──────────────────────────────────────────────────────────────────────────────────────────────────────────────┐ <- 120 символов
│Содержимое строки                                                                                                      │ <- 120 символов
│  Перенос с отступом                                                                                                   │ <- 120 символов
└───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘ <- 120 символов
```

- **Общая ширина**: 120 символов (рамки + содержимое)
- **Ширина содержимого**: `StartupBoxContentWidth = 118` символов
- **Рамки**: `│` (слева) + `│` (справа) = 2 символа
- **Итого**: 118 + 2 = **120 символов**

### Влезает ли в Logs Panel?
✅ **ДА!** Logs Panel = 112 символов, но с прокруткой можно увидеть все 120 символов строки лога.

### Перенос строк
- Если строка > 118 символов:
  - 1-я строка: максимум 118 символов
  - 2-я+ строки: отступ `"  "` (2 пробела) + максимум 116 символов
  - Разрыв по последнему пробелу (не ломает слова)

## Расчёт пространства

### Ширина
```
Консоль:         160 символов
├─ Logs Panel:   112 символов (70%)
└─ Commands:      48 символов (30%)

Логи:            120 символов
├─ Рамки:          2 символа (│ + │)
└─ Контент:      118 символов
```

### Высота
```
Консоль:         45 строк
├─ Status Bar:    1 строка
├─ Panels:       42 строки
│  ├─ Logs:      42 строки
│  └─ Commands:  42 строки
└─ Input:         2 строки
```

## Почему эти размеры?

1. **160 символов ширины**:
   - Логи: 120 символов влезают комфортно
   - Commands Panel: 48 символов достаточно для списка команд
   - Input: 160 символов позволяет вводить длинные команды

2. **45 строк высоты**:
   - Logs Panel: 42 строки = видно много логов одновременно
   - Не слишком большое окно (не заполняет весь экран)

3. **70/30 split**:
   - Logs важнее Commands
   - 70% для логов = 112 символов (достаточно для логов шириной 120)
   - 30% для команд = 48 символов (достаточно для списка)

## Константы в коде

### Program.cs
```csharp
private const int StartupBoxContentWidth = 118;
```

### BotUI.cs
```csharp
Console.SetWindowSize(160, 45);
Console.SetBufferSize(160, 2000);

// Logs Panel
Width = Dim.Percent(70)  // 70% от 160 = 112

// Commands Panel  
Width = Dim.Fill()       // 30% от 160 = 48
```

## Проверка совместимости

| Компонент | Требуемая ширина | Доступная ширина | Статус |
|-----------|------------------|------------------|--------|
| Startup Box | 120 | 112 (Logs Panel) | ⚠️ С прокруткой |
| Input Field | 160 | 160 | ✅ Влезает |
| Commands List | ~40 | 48 | ✅ Влезает |
| Status Bar | 160 | 160 | ✅ Влезает |

**Вывод**: Все компоненты влезают. Логи шириной 120 символов можно прокручивать горизонтально в Logs Panel (ширина 112).
